# 고민 분쇄기

고민을 적고 분쇄기 또는 벽난로로 보내면 다정한 포춘쿠키 메시지를 받는 반응형 웹게임입니다. React + TypeScript + Vite로 만들었으며 창문·커튼, 책장·랜턴, 별빛 병·책 더미는 GPT로 만든 개별 투명 PNG 레이어입니다. 각 이미지는 고유 비율을 유지하며 화면 크기에 따라 위치와 너비만 조절합니다. 벽과 테이블은 유동적인 CSS 표면으로 구성해 전체 배경을 늘리지 않습니다. 분쇄기·고양이·벽난로·포춘쿠키는 별도의 투명 PNG입니다. 쿠키는 자연스러운 접힘 형태이며 클릭 시 불규칙한 단면의 두 조각과 부스러기로 나뉩니다. 파티클, 움직이는 빛, 쿠키 열기, 효과음은 로컬 코드로 구현했습니다. 이미지 생성은 개발할 때만 수행했으며 게임 실행 중 API 호출이나 비용은 없습니다.

## 실행

Node.js 22.12 이상(또는 24 LTS)을 설치한 뒤 이 README가 있는 프로젝트 폴더에서 실행하세요.

```powershell
npm install
npm run dev
```

터미널에 표시된 Local 주소를 브라우저에서 엽니다. 개발 서버 종료는 Ctrl+C입니다.

```powershell
npm run build   # TypeScript 검사 + dist 생성
npm run preview # 프로덕션 빌드 미리보기
npm test        # DOM 기반 플레이 흐름 회귀 검사
```

휴대폰은 PC와 같은 Wi-Fi에서 터미널의 Network 주소로 접속할 수 있습니다. PC 방화벽 설정에 따라 접속이 제한될 수 있습니다. 모바일 HTTP 접속에서는 클립보드가 제한될 수 있어 메시지를 선택하여 복사하는 안내가 표시됩니다.

## 플레이와 조작

1. 마음 비우러 가기 → 고민 입력(최대 200 UTF-16 코드 단위, 일반적인 한글 200자).
2. 다 적었어요 → 종이 접기 → 분쇄기 또는 벽난로 선택.
3. 종이를 마우스 또는 터치로 도구 위에 끌어 놓습니다. 도구 영역 밖에 놓으면 원위치로 돌아옵니다.
   분쇄기에서는 종이가 투입구로 들어간 뒤 잘린 조각이 내부 수거함 안에서만 떨어집니다.

4. 드래그 대신 아래 보내기 버튼을 클릭하거나, 종이에 키보드 포커스를 두고 Enter/Space를 누를 수 있습니다.
5. 해소 애니메이션 후 포춘쿠키를 클릭합니다. 메시지를 복사하거나 이미지로 저장하거나 처음부터 다시 플레이합니다. 이미지로 저장을 누르면 카드 미리보기가 열리고 PNG 다운로드로 저장합니다.

Tab/Shift+Tab으로 버튼과 입력란 사이를 이동합니다. 상단 왼쪽 버튼으로 언제든 초기화할 수 있습니다. 소리는 기본 ON입니다. 브라우저 자동재생 제한 때문에 첫 클릭·터치·키보드 조작 때 시작되며, 상단 오른쪽에서 끌 수 있습니다. 재생이 시작되면 잔잔한 배경음이 서서히 시작되고, 장작 소리와 멀리서 들리는 작은 분쇄기 소리가 약 12–22초 간격으로 번갈아 흐릅니다(첫 환경음은 약 6.5초 후). 실제 분쇄·소각은 약 3.2초 동안 해당 작동음을 재생합니다. 일반 버튼 클릭, 화면 이동, 복사에는 별도 클릭음이나 알림음이 없습니다. 포춘쿠키를 열 때는 짧은 바삭한 파열음과 작아지는 부스러기 소리가 납니다. 운영체제의 동작 줄이기 설정도 지원합니다. 플레이 시간은 글 작성과 메시지를 읽는 시간을 포함해 약 1–2분을 예상하며, 강제 대기 시간은 최소화했습니다.

## 개인정보와 메시지

- 고민은 React 메모리 상태에만 존재합니다. 서버 전송, 로그, 쿠키, localStorage, sessionStorage, 데이터베이스를 사용하지 않습니다.
- 해소 애니메이션 완료 또는 초기화 시 고민 상태를 비웁니다. 새로고침하면 사라집니다.
- 업무/피로, 관계, 공부/미래, 자신감 관련 키워드를 순서대로 비교해 미리 작성한 문구를 선택합니다. 해당하지 않으면 기본 문구를 사용합니다. AI 호출이나 감정 진단은 없습니다.
- 복사 버튼은 긍정 메시지만 클립보드에 씁니다.
- 이미지는 프로젝트에 포함되며 분석 도구, 유료 API, 로그인은 없습니다. 웹폰트는 사용자가 지정한 jsDelivr 주소에서 다운로드합니다. 고민이나 행운 문구를 CDN에 전송하지 않습니다.
- Vite 개발 서버에는 개발용 HMR 연결이 있지만 고민 데이터 전송에는 사용하지 않습니다.

## 프로젝트 구조

```text
src/
  main.tsx       React 시작점
  App.tsx        5개 장면, 상태 전환, 메시지, 포인터 입력
  audio.ts       배경음·ASMR 환경음·작동음 및 음소거/탭 전환 수명 관리
  fortune-card.ts Canvas 기반 1080×1440 행운 카드 생성
  style.css      반응형 레이아웃, 작업실/분쇄기, 기본 애니메이션
  asset-style.css GPT 이미지 배치, 불빛/불씨, 고양이 숨쉬기, 쿠키 분리
public/assets/   GPT로 생성한 투명 PNG와 생성 프롬프트(이전 쿠키 버전 포함)
tests/
  flow.mjs       jsdom + React act 기반 흐름 회귀 검사
  audio.mjs      오디오 예약·음소거·취소·정리 검사(모의 AudioContext)

vite.config.ts   Vite React 설정
package.json     실행/빌드/테스트 명령
package-lock.json 고정된 의존성 버전
```

## 검증과 남은 확인

- TypeScript 및 Vite 프로덕션 빌드 검증.
- DOM 자동 검사: 빈 입력/공백 차단, 최대 길이 속성, 글자 수, 분쇄기 버튼 경로, 벽난로 키보드 경로, 포인터 드롭 영역 안/밖, 유형별 메시지, 복사/복사 실패 안내, 재시작, 진행 중 초기화, 소리 토글, 브라우저 저장소 미사용.
- 브라우저 미리보기 도구가 반복적으로 세션 만료를 반환하여 실제 브라우저 화면/오디오와 실기기 터치는 검증하지 못했습니다. DOM 검사는 화면 배치·실제 터치 하드웨어·CSS 애니메이션의 시각적 품질을 보증하지 않습니다.
- 마무리 QA 권장: PC 1440×900, 모바일 390×844 및 320px 너비에서 두 모드 플레이, 터치 드래그, 가로 화면, 소리 토글, 동작 줄이기, 실제 클립보드 확인.

CSS는 900px와 600px에서 레이아웃을 조정합니다. 포인터 이벤트로 마우스/펜/터치를 함께 처리하고, 모든 핵심 동작에는 키보드 또는 버튼 대안이 있습니다.





## 사운드 구성

- 배경음: 부드러운 사인파 화음이 8초 간격으로 겹치며 천천히 바뀝니다. 타격음 없이 서서히 커지고 작아집니다.
- 분쇄기: 낮은 모터 진동과 여과된 종이 마찰 소리를 겹칩니다.
- 장작: 바탕 불 소리를 낮추고, 2–3번씩 불규칙하게 모여 나는 짧고 건조한 타닥타닥 파열음을 강조했습니다. 배경 장작 소리와 실제 소각음 모두 적용됩니다.
- 포춘쿠키: 처음 갈라지는 바삭 소리와 잦아드는 작은 부스러기 소리가 약 0.4초 안에 끝납니다. 소리 OFF/탭 숨김에서는 재생하지 않습니다.
- 간헐적인 환경음은 실제 작동음의 약 23% 레벨입니다. 실제 작업 중에는 새 환경음을 겹쳐 시작하지 않습니다.
- 모든 소리는 Web Audio로 로컬 합성합니다. 실제 현장 녹음 파일이나 외부 음악 스트리밍을 사용하지 않습니다.
- 소리 OFF, 탭 숨김, 컴포넌트 해제 시 예약된 소리와 타이머를 정리합니다. 탭으로 돌아오면 배경음이 재개되며, 재시작 시 진행 중 작동음은 취소합니다.
- 기본 ON입니다. 첫 사용자 조작에서 오디오를 활성화합니다. 처음 누른 버튼이 소리 OFF라면 재생하지 않습니다. 오디오를 지원하지 않으면 안내를 표시하고 게임은 계속 동작합니다.
- 오디오 테스트는 모의 AudioContext로 재생 예약과 정리를 확인합니다. 실제 스피커/헤드폰 청감과 모바일 브라우저 오디오 재생은 별도로 확인해야 합니다.


## 행운 카드 이미지 저장

포춘쿠키 결과에서 **이미지로 저장 → PNG 다운로드**를 누르세요. 1080×1440 세로 PNG에 작업실 배경, 쿠키, 고양이, 크림색 종이와 행운 문구를 함께 그립니다. 글자는 실제 텍스트로 렌더링하며 한글 길이를 측정해 줄을 나눕니다. 미리보기는 닫기 버튼이나 Escape로 닫을 수 있습니다.

모바일 브라우저가 다운로드 대신 이미지를 열면 이미지를 길게 눌러 저장할 수 있습니다. 생성 작업은 브라우저 Canvas 안에서 처리하고 서버에 전송하지 않습니다. 원래 입력한 고민은 카드에 포함하지 않습니다. 카드에는 긍정 메시지만 저장합니다. 배경 이미지 로딩이나 Canvas 사용이 실패하면 다시 시도할 수 있는 안내를 표시합니다.

카드 자동 검사는 자산 로딩, 문구 배치, PNG 생성 요청 및 실패 처리를 모의 Canvas로 확인합니다. 실제 브라우저의 PNG 인코딩, 다운로드 UI 및 카드 최종 시각 검증은 별도 확인이 필요합니다.

## 웹폰트

기존 Georgia 영역(게임 타이틀, 영문 소제목, 종이 라벨)은 GyunMyeongjo로, 기존 맑은 고딕 본문·버튼·행운 문구는 Heejoy로 바꿨습니다. `src/fonts.css`에 GyunMyeongjo 400/700과 Heejoy 100–900을 등록했습니다. 폰트는 실제 사용하는 굵기만 브라우저가 요청합니다. 다운로드에는 인터넷 연결이 필요하며 로딩 중에는 대체 폰트를 표시합니다.

PNG 행운 카드는 Heejoy 400/700 로딩을 기다린 뒤 글자 너비를 계산하고 그립니다. 폰트 로딩에 실패하면 이미지 생성 실패 안내 후 재시도할 수 있습니다.

## 배경 레이어와 반응형 배치

- `room-window-perspective.png`: 왼쪽 벽의 원근감을 그린 창문·커튼·덩굴
- `room-shelf-perspective.png`: 오른쪽 벽의 원근감을 그린 책장·랜턴·덩굴
- `room-star-jar.png`: 별빛 병·책 더미
- 고양이와 벽난로는 기존 독립 이미지 유지

`Room`의 각 장식은 별도 레이어입니다. 창문과 책장은 벽 높이를 따라 `height: 100%`와 `width: auto`로 원본 비율을 유지하며 확대하고, 양옆의 프레임 안에서 초과 영역을 잘라냅니다. 작은 벽 장식처럼 축소하지 않고 화면 위에서 테이블까지 이어지는 구도입니다. 고양이와 별빛 병은 너비 기준 비례 크기이며 900px/600px·낮은 가로 화면 분기에서 위치를 조절합니다. 랜턴과 병의 발광 효과도 해당 이미지에 종속되므로 함께 이동합니다. 행운 카드 역시 동일한 개별 이미지를 원본 비율대로 합성합니다. 이전 일체형 배경 PNG는 참고용으로 남아 있지만 화면과 카드에서는 사용하지 않습니다.



## 통합 작업실 배경

창문·커튼·책장·랜턴·벽·테이블은 접점과 그림자가 자연스럽게 이어지는 한 장면으로 다시 그렸습니다. `workshop-unified-desktop.png`와 `workshop-unified-mobile.png`를 화면 비율에 따라 바꾸고, CSS `object-fit: cover`로 원본 비율을 유지하며 가장자리만 자릅니다. 고양이와 별빛 병은 독립 이미지로 남아 움직임과 빛 효과를 유지합니다. 행운 카드도 모바일 통합 배경을 사용합니다. 이전 개별 건축 이미지들은 참고용 파일이며 게임에서는 사용하지 않습니다.
